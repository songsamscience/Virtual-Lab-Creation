성취기준에서 출발하는 가상실험실 제작 프롬프트

과목과 성취기준을 고르고 학생이 바꾸는 것·달라지는 것 두 칸만 적으면, 생성형 AI에 그대로 붙여넣는 완성형 제작 요청서가 만들어집니다. 과학은 2022 개정 성취기준 목록을 제공하고, 다른 과목은 성취기준을 직접 붙여 넣습니다. 나머지는 AI가 지침에 맞춰 정하고 «확인 필요»로 알려 줍니다.

1과목·성취기준 고르기› 2바꾸는 것·달라지는 것 적기› 3복사해서 AI에 붙여넣기

1

교육과정 정렬

과목과 성취기준만 고르면 실험실 이름과 학습 목표가 자동으로 채워집니다. 프롬프트의 뼈대가 되는 단계입니다.

목록에 없는 성취기준 직접 적기 (초등·고2 이상·다른 과목 연계)

교육과정 문서(NCIC)나 교과서 지도서에서 복사해 붙여 넣으세요. 학습 목표가 여기서 자동으로 만들어집니다.

고쳐 쓰면 자동 채움이 멈춥니다.

2

실험 설계

학생이 바꾸는 것과 달라지는 것, 두 칸이 핵심입니다. 비워 둔 칸은 AI가 교과서 수준으로 정한 뒤 «확인 필요»로 따로 알려 주므로 되묻는 왕복이 없습니다.

범위를 정해 두면 AI가 임의로 정밀도를 부풀리지 않습니다.

분해능을 적으면 AI가 그럴듯해 보이려는 임의의 ±0.1~0.3 노이즈를 넣지 말라는 규칙이 함께 들어갑니다.

이 칸이 프롬프트에서 “무엇을 정확히 재현하고 무엇을 단순화했는지”를 화면에 밝히라는 지시로 바뀝니다.

3

학습 장치 · 화면 느낌 선택

기본값(공통 코어만 · 화면은 AI가 정함)으로도 완성됩니다. 탐구 질문·그래프·리포트가 필요하거나 화면의 장면을 직접 정하고 싶을 때만 엽니다.

① 핵심 스테이지 + 조작 1~3개 · ② 읽을 수 있는 상태·측정값 + 초기화 · ③ 44px 터치·키보드·색 외 표현 + 상태 서술 문장 · ④ 모델의 근거·조건·단위·단순화 표시 · ⑤ 도움말과 실패 시 폴백 · ⑥ 결과 저장(PNG) 버튼 · ⑦ 전체화면 · 다크/라이트 테마

모범 답안을 열면 처음 답안은 잠기고 바로 아래에 «다시 쓰기» 칸이 열리는 단일 정책이 프롬프트에 들어갑니다. 상황을 묻는 문항에는 그 상황을 바로 해 볼 수 있는 간이 실험 그림을 붙이도록 지시합니다.

화면 느낌 비우면 AI가 지침에 맞춰 정하고, 코드보다 먼저 브리프 표로 보여 줍니다

“깔끔하게”, “예쁘게” 같은 말 대신 눈에 보이는 장면으로 쓰면 AI가 매번 다른 화면을 만듭니다.

비워 두면 AI가 지침에 맞춰 정합니다. 원하는 색이나 구도가 이미 있을 때만 열어서 쓰세요.

4

완성 프롬프트

통째로 복사해 생성형 AI에 붙여넣으세요. 브리프 표 → 확인 필요 목록 → 완성 HTML → 점검 결과 순으로 응답하도록 지시되어 있습니다.
